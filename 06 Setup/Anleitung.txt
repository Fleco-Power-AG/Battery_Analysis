First time setup

1. Install Miniconda: https://docs.conda.io/en/latest/miniconda.html (skip if Anaconda or Miniconda is already installed)
2. Clone the repo:
   Open a terminal (cmd), navigate to the folder where you want your working folder, then run:
   git clone https://github.com/Fleco-Power-AG/Battery_Analysis
3. Double-click setup.bat (creates the "batterieanalyse" environment)


Running a battery analysis

1. Create an input Excel file for your configuration:
   1.1 Copy the template matching your setup/case from the "Vorlagen" folder into the root folder.
   1.2 Adjust the input Excel for your case (the name can be edited, but it must still start with "Inputs_").
2. Double-click run_battery_analysis.bat. Drag your input Excel file (from the root-Folder, not the "Vorlagen") into the console window that opens and press Enter (or drag the file directly onto the run_battery_analysis.bat icon instead, which passes it in automatically without any prompt).
3. Validate the output and check the report.
