## Quickstart (Windows)

1. Miniconda installieren: https://docs.conda.io/en/latest/miniconda.html
2. Repo klonen:
   git clone <dein-repo-url>
   cd <repo-ordner>
3. Im Ordner 06 Setup: setup.bat doppelklicken (erstellt das Environment "batterieanalyse")
4. Für die Durchführung gibt es 3 Möglichkeiten:
	- reine analyse ohne sweep analyse und schönem Bericht: run_battery_analysis.bat doppelklicken
	- Schöner Bericht mit/ohne Sweep Analyse: run_alles.bat
	- reine Sweep analse: run_battery_sizing.bat
